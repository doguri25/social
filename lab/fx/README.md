# 화질 올리기 목업 (lab/fx)

게임(엔진 Babylon.js, 화면·인물·무대)은 그대로 두고, 그 위에 **WebGL GLSL 셰이더 + Canvas2D** 를 얹어 화질만 올린 목업입니다. **Vite** 로 묶습니다.
1권 첫 장면 두 번째 컷(「나는 수아예요…」) 화면에서 시작하고, 위 가운데 단추로 켜고 끄며 지금 게임과 견줄 수 있습니다.

| 무엇 | 어떻게 | 파일 |
|---|---|---|
| 인물 재질 | GLSL: 빛과 그늘 경계를 부드러운 두 단계로, 그늘은 보랏빛, 밝은 쪽 가장자리에 따뜻한 빛 (게임 색과 60% 만 섞음) | `src/glsl/toon.glsl` |
| 색 보정 | GLSL 후처리: 선명도, 칙칙한 색만 맑게, 따뜻한 빛·보랏빛 그늘, 부드러운 대비, 가장자리, 종이 결 (무대와 컷 그림 모두) | `src/glsl/grade.frag` |
| 얼굴 | Canvas2D: 게임의 얼굴 그림(`drawFace`)을 네 배(1024)로 | `src/fx.js` |
| 머리카락 | Canvas2D: 머리카락 결을 두 배 크기로 더 촘촘하게 | `src/fx.js` |
| 종이 결 | Canvas2D 로 그린 되풀이 무늬를 색 보정에서 아주 옅게 | `src/fx.js` |

## 쓰는 법

```
cd lab/fx
npm install
npm run dev      # 고치며 보기
npm run build    # dist/ 에 만든다 (저장소에 함께 올려 Vercel 미리보기 /lab/fx/dist/ 로 연다)
```

빌드할 때 저장소 맨 위의 `build.sh` 로 게임을 만든 뒤(`dist/artifact.html`), 그 모듈 스크립트 끝에 `src/fx.js` 를 이어 붙입니다.
fx.js 는 게임과 같은 모듈 안에서 돌아서 게임의 장면·인물·카메라를 그대로 씁니다 (게임 코드는 고치지 않음).

주소: `?fx=0` 이면 꺼진 채로 시작, `?book=1&scene=s01&mock=1` (기본) 이면 두 번째 컷까지 저절로 넘깁니다.

해 보고 뺀 것: 발밑이 또렷한 부드러운 그림자(PCSS)는 화면이 크게 느려져서(학교 기기), 화면 해상도를 두 배로 올리면 빛 번짐이 세져 흰 탁자·종이가 하얗게 날아가서.
