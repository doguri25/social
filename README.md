# 마음 극장 (가칭)

사회정서를 다루는 동화 5권을 3D 디오라마 무대와 웹툰 컷으로 보여 주고, 사건마다 행동을 골라 이야기의 결과가 달라지는 초등 3~4학년 수업용 게임입니다. 엔진은 Babylon.js 9.27.1, 빌드 방식은 [폭주 구구단](https://github.com/doguri25/pokju-edu)과 같습니다.

현재 버전: **v0.3.0** (1권 「다시 이어진 길」 처음부터 결말 3종까지). 바뀐 점은 [`CHANGELOG.md`](CHANGELOG.md), 내려받기는 [Releases](https://github.com/doguri25/social/releases)

기획은 [`docs/PRD.md`](docs/PRD.md)에 있습니다.

## 한 권의 흐름

1. 책장에서 1권을 누릅니다.
2. 한 화면에 왼쪽은 3D 무대, 오른쪽은 웹툰 컷과 할 일 칸이 있습니다. 무대는 끌어서 360도 돌려 볼 수 있고, 카메라 쪽 벽은 저절로 걷힙니다. 노란 「?」나 인물(또는 왼쪽 아래 인물 카드)을 누르면 짧은 말이 나옵니다.
3. 장면 첫 장을 보고 「이야기 보기」, 그다음은 「다음」(또는 Enter)으로 한 컷씩 넘깁니다. 「이전」으로 그 장면의 지난 컷을 다시 봅니다. 고를 것이 나오면 컷 그림이 줄어들어 화면이 넘치지 않습니다.
4. 중간중간 이렇게 멈춥니다.
   - **나라면 어떻게 할까?** (3면, 4면, 9면): 원작과 다른 쪽을 고르면 「만약에…」 컷을 보고 원작으로 돌아옵니다.
   - **마음 살피기**: 감정 카드 8장 가운데 하나를 고르면 인물의 진짜 마음을 보여 줍니다. 정답·오답 표시는 없습니다.
   - **숨 고르기** (13면, 16면): 동그라미를 누르고 있으면 들이쉬고, 떼면 내쉽니다. 세 번.
   - **갈림길** (13면 계단, 15면 밤): 고른 장면으로 이어집니다.
   - **하고 싶은 말 고르기** (17면): 사과할 말을 여러 개 고르면 유나가 차례로 말하고, 그 말에 따라 결말이 정해집니다.
5. 결말 3종: 다시 이어진 길(원작) / 붙였지만 아직 어색한 길 / 끊어진 채 걸린 지도. 「내가 고른 길」에서 지나온 갈림길을 누르면 그 장면에서 다르게 골라 볼 수 있습니다.

## 수업에서

- **함께 보기**(설정): 전자칠판용. 고르는 화면에 선생님 질문, 생각 시간(30/60/90초), 선택지마다 손든 사람 수가 나옵니다. 선생님이 하나를 눌러 정합니다.
- **수업 링크**: `?book=1` 로 열면 책장을 건너뛰고 1권으로 들어갑니다. `&mode=class` 를 붙이면 함께 보기로 엽니다. 특정 장면부터: `?book=1&scene=s13`.
- 기록(본 결말, 감정 카드 답)은 이 브라우저에만 `social-v1` 이름으로 저장되고 어디로도 보내지 않습니다.
- 읽어 주기는 기기에 한국어 목소리가 있을 때만 보입니다. 배경음악은 없고 효과음은 설정에서 끌 수 있습니다.

## 실행

- `index.html`을 브라우저로 엽니다. Babylon.js(약 1.8MB gzip)와 글꼴을 인터넷에서 불러오므로 온라인 상태여야 합니다.
- 저장소를 공개로 바꾸고 Pages에서 `main` 브랜치를 고르면 `https://doguri25.github.io/social/` 주소로 열 수 있습니다.

## 고친 뒤 다시 만들기와 시험

```sh
sh build.sh                       # src/ + data/defs.json + stories/*.json → index.html, dist/artifact.html
node tests/story.test.js          # 이야기 데이터 검사: 이름 목록, 모든 길이 결말에 닿는지
node tests/browser.test.mjs warm  # 크롬(화면 없이, 소리 끔)으로 끝까지 넘기기. okay, sorry, phone, every 도 됨
```

js 조각은 모두 하나의 모듈 스크립트 안에 들어가므로 `build.sh`에 적힌 순서를 바꾸면 안 됩니다.

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 바로 열 수 있는 완성 파일 |
| `dist/artifact.html` | Claude 아티팩트에 게시하는 본문 조각 |
| `src/` | 소스 조각: `head.html`(화면과 스타일), `js_base`(저장·소리·읽어 주기), `js_face`(얼굴 그림), `js_map`(모둠 지도 그림), `js_world`(엔진·카메라·빛·재질·모델·벽 자르기·화질), `js_char`(2등신 인물·자세), `js_stage`(무대 7곳·소품), `js_shot`(컷 카메라·찍기·망점·얼굴 사진), `js_panel`(오른쪽 컷·이전/다음), `js_sheet`(할 일 칸: 고르기·감정·말 고르기·숨 고르기·결말), `js_story`(장면 진행·결말·내가 고른 길), `js_ui`(둘러보기·인물 카드·책장·설정) |
| `data/defs.json` | 무대별 자리·물건·카메라, 표정·자세 이름 |
| `stories/book1.json` | 1권 이야기 데이터 (원고 글은 그대로, 컷으로 나눔) |
| `assets/models/` | Kenney CC0 3D 모델 (가구, 나무, 집). 빌드 때 페이지 안에 들어감 |
| `tests/` | 이야기 데이터 검사, 브라우저 시험(`cdp.mjs` 공용 도구) |
| `docs/PRD.md` | 기획 문서 |

## 알아 둘 점

- 1권 원고의 글은 고치지 않고 컷으로 나눠 썼습니다. 새로 쓴 글은 「만약에」 컷, 갈래 장면(13b·13c·15b·15c), 결말 두 가지에만 있습니다.
- 학교 크롬북·태블릿 실제 기기에서는 아직 시험하지 않았습니다. Babylon 엔진 파일이 커서 반 전체가 처음 한꺼번에 받을 때 느릴 수 있습니다.
