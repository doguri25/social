# 컷 애니메이션 동작 적는 법

이야기의 그림 컷은 처음 나올 때 한 번 움직인 뒤 멈춘 삽화가 된다. 컷마다 인물이 무엇을 할지는
`stories/anim/<책>.json` 에 적는다 (이야기 파일 `stories/<책>.json` 은 건드리지 않는다).
확인: `python3 tools/anim_check.py <책>`

## 모양

```json
{
  "<장면 id>": { "<컷 번호>": { ...이 컷의 동작... } },
  "end:<결말 id>": { "<컷 번호>": { ... } }
}
```

- 컷 번호는 그 장면 `panels` 배열에서의 순서(0부터). `shot` 이 있는 컷(그림 컷)에만 적는다.
  `set`·`note`·`text`·`feel`·`activity`·`phone` 뿐인 컷에는 적지 않는다.
- 적지 않은 컷은 표정에 맞는 자동 동작(기쁨은 폴짝, 화남은 발 구르기 등)만 한다.

## 인물의 동작

`"<인물 id>": [[때, 자세, 표정, 동작], ...]`

- 때: 0~0.8 (컷 3.6초 가운데 언제 그 자세가 되는가). 보통 0.2~0.3. 여러 줄이면 때가 커지는 순서.
- 자세: 그때까지 바뀔 자세. `null` 이면 이 컷의 자세(컷의 `poses`, 없으면 무대에서 정한 자세).
- 표정: `null` 이면 이 컷의 표정.
- 동작: 그 자세가 된 뒤 다음 줄로 넘어가기 전까지 되풀이하는 움직임.
- 마지막에는 늘 이 컷의 자세·표정(삽화)으로 돌아와 멈춘다. `["end", 0, 0, "동작"]` 을 넣으면 삽화 자세가 된 뒤 그 동작을 한다.
- 다섯째 값(선택): 그 자세로 바뀌는 데 걸리는 때. 천천히 바꿀 때 0.3~0.5 (예: 벌린 팔을 천천히 내린다).

자세: stand, sit, sitlow, walk, wave, down(고개 숙임), cross(팔짱), reach(팔 뻗기), tug(잡아당기기), phone, hold(두 손으로 쥠),
cover(얼굴 가림), jump, point(손가락질), show(든 것을 보임), clasp(두 손 모음), throw(던지려 팔을 젖힘), open(받으려 팔 벌림),
dodge(몸을 비킴), call(두 손을 입가에), dance.

표정: calm, joy, laugh, sad, angry, worried, surprised, shy, hurt, yawn, cry.

동작:
- 기쁨·신남: joy(폴짝 뛰며 한 손 흔들기), cheer(만세하며 폴짝), clap(손뼉), laugh(몸 젖히며 웃기), wave(한 손 흔들기),
  greet(이쪽저쪽 보며 인사), pump(든 것을 번쩍 들기), dance(엉덩이춤), spin(한 바퀴 돌기), sway(몸 흔들기)
- 화·다툼: angry(발 구르기), fist(주먹 쥐기), blame(손가락질하며 따지기), shake(고개 젓기), shout(몸을 내밀어 외치기), away(외면)
- 슬픔·걱정·머쓱함: sad(고개·어깨 처짐), sigh(한숨), worried(두리번거리며 손 모으기), fidget(손 만지작), toe(발끝으로 바닥 누르기),
  shy(몸 꼬기), scratch(뒷머리 긁기), bow(꾸벅 — 사과·인사), cry, squeeze(품에 안은 것을 꽉 쥠)
- 진정: breath(깊은 숨), nod(끄덕임), look(두리번), calm(가만히 몸무게 옮기기), still(아무것도 안 함)
- 놀람·넘어짐: jolt(움찔), tumble(뒤로 엉덩방아), trip(앞으로 휘청)
- 운동: ready(경기 준비 자세로 좌우 움직임), windup(던지기 직전 힘 모으기), dodge(좌우로 폴짝 피하기), brace(받을 준비), run, walk
- 생활: write(수첩에 적기 — 오른손에 수첩을 든 인물), erase(지우기), close(든 수첩을 덮어 내림), offer(든 것을 조용히 내밂), give(건네고 받기),
  eat(먹기), poke(젓가락으로 콕콕), wash(손 씻기), pat(토닥이기), bounce(공 튀기기), highfive(손바닥 마주치기), gaze(주인공 쪽을 지그시 봄), balance, yawn

말하는 사람(컷의 `lines` 에 있는 인물)은 따로 적지 않아도 손짓하며 끄덕인다.

## 이동

- 저절로: 앞 컷 뒤의 `set` 으로 인물 자리가 바뀌었으면 그 자리에서 걸어(멀면 뛰어) 온다. 새로 나온 인물은 걸어 들어온다. 적을 것 없음.
- `"from": {"<id>": [오른쪽, 앞]}`: 삽화 자리에서 그만큼(m) 떨어진 데서 걸어 들어온다. 뒤에서 다가오면 `[0, -2.2]`.
- `"path": {"<id>": [[때, 오른쪽, 앞], ...]}`: 제자리에서 벗어났다 돌아오는 길(m). 도움닫기 `[[0.15,0,-0.4],[0.3,0,0.4]]`, 좌우로 피하기 `[[0.2,-0.7,0],[0.42,0.5,0]]`.
- `"run": ["<id>"]`: 걷지 않고 뛴다.

## 공

- 저절로: 앞 컷 뒤로 공 자리(`set.ball`)가 바뀌었으면 앞 자리에서 포물선으로 날아온다. 던진 사람은 팔을 휘두르고, 바닥에 닿으면 튄다.
- `"hit": "<id>"`: 이 컷에서 그 인물이 공에 맞는다 (맞는 순간 밀리며 넘어지거나 휘청이고, 공은 튕겨 바닥에 떨어진다). `"hitLight": true` 면 움찔만.
- `"ball": false`: 공을 움직이지 않는다.

## 그 밖

- `"cheer": 0~1.2`: 배경 아이들이 들썩이는 정도. 적지 않으면 가만히 있다. 신나는 컷 0.8~1, 술렁이는 컷 0.3~0.5.
- `"cam": {"back": 배, "turn": 도, "up": m}`: 카메라가 삽화 자리보다 그만큼 물러난(1.2) / 다가간(0.8) / 옆으로 돈 데서 시작해 삽화 자리로 온다.
  적지 않으면 컷 성격에 맞춰 저절로 정한다(장면 첫 넓은 컷은 물러나며 보여 주기, 외침·효과음은 빠르게 다가가기, 물건·속상한 얼굴은 천천히 다가가기, 나머지는 고정).
  `"cam": false` 면 고정. 꼭 필요한 컷에만 적는다: 마음이 크게 흔들리는 순간(1.15~1.3), 혼자 남은 모습(0.8), 두 무리를 훑어 보여 줄 때(turn 12~15).
